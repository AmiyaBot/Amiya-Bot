## 1.1 版本锁定

`requirements.txt:1`：

```
amiyabot==2.0.9
```

用 `==` 而非 `~=`，不接受任何版本漂移。其余依赖见 `requirements.txt:2-15`（`jionlp`、`pypinyin`、`attridict`、`cos-python-sdk-v5`、`gitpython`、`jsonschema`、`srsly`、`requests-html`、`baidu-aip`、`chardet`、`jinja2`、`opencv-python`、`tencentcloud-sdk-python`）。

`pluginsDev/requirements.txt` 是插件子模块独立的依赖文件，与主仓库不同（插件在运行期由宿主按需装载，其依赖不并入主仓库的 `requirements.txt`）。

## 1.2 本项目如何使用它

启动链路：

| 阶段 | 位置 | 说明 |
| --- | --- | --- |
| 入口 | `amiya.py:34-35` | `run_amiya([bot.start(launch_browser=True), app.serve()])` |
| 冻结模式初始化 | `amiya.py:4` → `core/frozen.py` | 最先 import，用于修正 frozen 下的资源路径 |
| 资源/GUI | `amiya.py:21` | `BotResource.download_bot_resource()` |
| 事件循环 | `amiya.py:12-18` | `asyncio.run(main())`，插件加载与 `init_task` 并发 |
| 多账号实例 | `core/__init__.py:39` | `bot = MultipleAccounts(*BotAccounts.get_all_account())` |
| HTTP 服务 | `core/__init__.py:29-31` | `ServerConfig()` + `HttpServer(host, port, app_conf)` |

`core/__init__.py:9` 使用 `from amiyabot import *` 通配导入，这是本仓库大量符号（`Message`、`Chain`、`event_bus`、`log`、`ChainConfig` 等）能直接可用的原因。插件通常写 `from core import Message, Chain, AmiyaBotPluginInstance`，见 `pluginsDev/src/func/main.py:6,9`、`pluginsDev/src/user/mainBot.py:10`。

## 1.3 安装命令

```bash
pip install amiyabot
```
