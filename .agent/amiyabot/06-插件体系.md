## 1. `PluginInstance` vs `AmiyaBotPluginInstance`

官方文档：[AmiyaBotPluginInstance](https://www.amiyabot.com/develop/plugin/amiyaBotPluginInstance.html) · [插件生命周期](https://www.amiyabot.com/develop/plugin/life.html)

| 对比项 | `PluginInstance` | `AmiyaBotPluginInstance` |
| --- | --- | --- |
| 来源 | `from amiyabot import PluginInstance` | `from core import AmiyaBotPluginInstance`（本项目自定义） |
| 定义位置 | amiyabot 包内（**外部**） | `core/plugins/customPluginInstance/amiyaBotPluginInstance.py:23` |
| 继承关系 | 继承 `BotHandlerFactory` | `class AmiyaBotPluginInstance(PluginInstance)`（`amiyaBotPluginInstance.py:23`） |
| 额外能力 | — | `instruction`、`requirements`、`get_config`/`set_config`、JsonSchema 校验、配置迁移、`deprecated_config_delete` |
| 适用场景 | 简单插件 | 需要控制台配置管理的插件 |

两种都有实际使用：

- 纯 `PluginInstance`：`pluginsDev/src/admin/main.py:11`、`pluginsDev/src/arknights/calculator/main.py:11`
- `AmiyaBotPluginInstance`：`pluginsDev/src/func/main.py:16`、`pluginsDev/src/user/mainBot.py:20` 等约 20 处


`super().__init__` 的位置参数顺序是 `(name, version, plugin_id, plugin_type, description, document, priority)`，即 `PluginInstance` 的构造签名。

最完整调用示例（`pluginsDev/src/func/main.py:16-26`）：

```python
bot = AmiyaBotPluginInstance(
    name='功能管理',
    version='2.7',
    plugin_id='amiyabot-functions',
    plugin_type='official',
    description='管理已安装的插件功能',
    document=f'{curr_dir}/README.md',
    instruction=f'{curr_dir}/README_USE.md',
    global_config_default=f'{curr_dir}/configs/global_config_default.json',
    global_config_schema=f'{curr_dir}/configs/global_config_schema.json',
)
```

> ⚠️ `document` / `instruction` 传的是**文件路径**，框架加载后属性会变为**文件内容**：`core/server/plugin.py:79-80` 用 `check_file_content(item.document)` 处理（该函数定义于 `core/util/common.py:52`），`pluginsDev/buildPlugins.py:64-68` 也是「是文件则读内容」。

`global_config_default` 也可用 **yaml**：`pluginsDev/src/user/mainBot.py:38` `global_config_default=f'{curr_dir}/config_default.yaml'`。

### 2.1 配置约束

`channel_config_*` 与 `global_config_*` 的约束（`amiyaBotPluginInstance.py:61-62`）：

```python
if self.__global_config_default is None and self.__channel_config_default is not None:
    raise ValueError('If you provide channel default, you must also provide global default.')
```

schema 与 default 的约束（`amiyaBotPluginInstance.py:226-234`）：

```python
if schema is not None:
    if default is None:
        raise ValueError('If you provide schema, you must also provide default.')
    try:
        jsonschema.validate(instance=default, schema=schema)
    except jsonschema.ValidationError as e:
        raise ValueError('Your json default does not fit your schema.') from e
```

> ⚠️ 两条约束都在**启动时**校验，违反会直接 `ValueError` 导致启动失败。新增 `channel_config_default` 字段时必须同步检查 global 侧。

### 2.2 配置版本迁移

`amiyaBotPluginInstance.py:87-97`：数据库配置版本旧于插件版本时执行 `merge_dict` 逐项更新并写入审计记录。

`amiyaBotPluginInstance.py:128-218` `deprecated_config_delete`：默认 **7 天**后删除既不在 default 也不在 schema 中的配置项（`deprecated_config_delete_days=7`，`amiyaBotPluginInstance.py:39`）。设为**负数或 `None` 可禁用**（`:133-134`）。

### 2.3 `get_config` 降级链

`amiyaBotPluginInstance.py:352-414`：频道配置 → 频道默认 → 全局配置 → 全局默认 → `None`，**不抛异常**。

> ⚠️ `:354-361`：若插件**未提供 `channel_config_default`**，即使传了 `channel_id` 也**不会**读取频道配置（只会尝试读，失败则降级到全局）。注释原文：「以GUI为准，如果插件没有提供 channel_default，就表示该插件不支持设置频道级别配置，直接降级」。

## 4. 插件 zip 结构

`plugins/amiyabot-admin-1.6.zip` 解包结果（文件位于 **zip 根**，无外层目录）：

```
__init__.py
README-public.md
README.md
logo.png
main.py
```

打包逻辑 `pluginsDev/buildPlugins.py:79-85`，用 `target.replace(plugin, '').strip('\\')` 把文件写到 zip 根：

```python
package = f'{dist}/{instance.plugin_id}-{instance.version}.zip'

with zipfile.ZipFile(package, 'w') as pack:
    for plugin_root, _, plugin_files in os.walk(plugin):
        for index, filename in enumerate(plugin_files):
            target = str(os.path.join(plugin_root, filename))
            if '__pycache__' in target:
                continue
            pack.write(target, target.replace(plugin, '').strip('\\'))
```

命名规则 `{plugin_id}-{version}.zip`（`buildPlugins.py:77`）。`plugins/` 目录中的实际产物（如 `amiyabot-functions-2.7.zip`、`amiyabot-user-3.2.zip`）与该规则一致。

官方文档 [打包插件](https://www.amiyabot.com/develop/plugin/build.html)：将整个插件文件夹压缩为 zip；若插件用了第三方库，**需要手动把库文件放进插件包**（`import pypyodbc` 会优先使用插件内的 `pypyodbc.py`）。

## 5. 插件源码目录结构

官方文档 [创建插件](https://www.amiyabot.com/develop/plugin/create.html)：

```text
Amiya-Bot
├── pluginsDev
│   ├── myPlugin
│   │   ├── __init__.py
│   │   └── main.py
```

本仓库一致，例如 `pluginsDev/src/func/`（含 `__init__.py` + `main.py` + `database.py`）。

**硬性要求**：

1. `__init__.py` 内导出，命名**必须是 `bot`**：`from .main import bot`
2. `__init__.py` 内**不要写多余代码** —— 插件加载时会临时把插件目录加入 `sys.path`，会污染主程序全局对象。

`pluginsDev/src/func/__init__.py` 符合此约定（可通过 `from pluginsDev.src.func import bot` 验证，见 `run_test.py:15`）。

## 7. 插件依赖 `Requirement`

`core/plugins/customPluginInstance/requirement.py:6-9`：

```python
class Requirement:
    plugin_id: str
    version: Optional[str] = None
    official: bool = False
```

依赖解析与自动下载 `core/plugins/__init__.py:67-165`：

- 本地已有依赖但**版本不匹配** → 拒绝安装（`:83-89`）
- 本地无依赖 → `find_plugin_from_remote`（`:110`）
  - `official=True` → 从 COS 的 `plugins/official/plugins.json` 找（`:130`）
  - `official=False` → 从插件商店 `{plugin}/getPluginRelease?plugin_id=...` 找（`:147-149`）
- 递归检查「依赖的依赖」（`:165`）

> ⚠️ 版本比对是**字符串全等**（`!=`），不做语义化比较。因此 `Requirement('x', '1.0')` 要求的是**字面量 `'1.0'`**，而商店返回什么版本号就按字面量比对（见 `core/plugins/__init__.py:81-103`）。

## 8. `install()` / `uninstall()` / `load()`

继承 `PluginInstance` 并覆盖 `install()` / `uninstall()`。

`pluginsDev/src/user/mainBot.py:20-26`：

```python
class UserPluginInstance(AmiyaBotPluginInstance):
    def install(self):
        if not os.path.exists(face_dir):
            shutil.copytree(f'{curr_dir}/face', face_dir)

    def uninstall(self):
        shutil.rmtree(face_dir)
```

`pluginsDev/src/arknights/gacha/main.py:53-60`（`install` 中启动异步任务 + 复制文件）：

```python
def install(self):
    asyncio.create_task(self.sync_pool())
    bot_caller['plugin_instance'] = self

    # 把demo卡池文件复制到自定义卡池文件夹
    dest_file = f'{custom_pool}/f175f6a942a746b6a0e00b151253955a.json'
    demo_file = f'{curr_dir}/config/f175f6a942a746b6a0e00b151253955a.json'
    shutil.copyfile(demo_file, dest_file)
```

> ⚠️ `install()` 与 `uninstall()` 是**同步**函数（无 `async def`），**不能直接 `await`**。需要异步操作时用 `asyncio.create_task(...)`。

### 8.1 `load()` 懒加载

`AmiyaBotPluginInstance.load()` 默认是**空实现**（`amiyaBotPluginInstance.py:250-251`）：

```python
def load(self):
    ...
```

由 `PluginsLoader.install_loaded_plugins` 在所有插件安装后统一调用（`core/plugins/__init__.py:57-60`）：

```python
# 然后对所有插件执行懒加载（如果有的话）
for plugin_id, item in self.bot.plugins.items():
    if isinstance(item, AmiyaBotPluginInstance):
        item.load()
```

`LazyLoadPluginInstance` 是**兼容性别名**（`core/plugins/customPluginInstance/lazyLoadPluginInstance.py:4`）：

```python
# 兼容性保留这个类变量
LazyLoadPluginInstance = AmiyaBotPluginInstance
```

两者**完全等价**，新代码应直接用 `AmiyaBotPluginInstance`。
