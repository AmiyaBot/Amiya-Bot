# 7. 数据库

`amiyabot.database` 的连接方式、`ModelClass` + `@table` 模型定义、字段类型、查询扩展方法与 `MysqlConfig`。

相关：[插件体系](06-插件体系.md) · [网络与工具](08-网络与工具.md)

官方文档：[数据库支持](https://www.amiyabot.com/develop/tools/databaseSupport.html)

---

## 1. `connect_database`

两种形态：

```python
# Sqlite（core/database/bot.py:18）
db = connect_database('amiya_bot' if is_mysql else 'database/amiya_bot.db', is_mysql, config)

# MySQL（core/database/__init__.py:7）
config = MysqlConfig(**setting['config']) if is_mysql else None
```

位置参数顺序是 `(db_name, is_mysql, config)`。`config` 可以是 `MysqlConfig` 实例。

官方文档：`connect_database('database_name')` 默认创建 Sqlite；MySQL 用 `is_mysql=True, config=MysqlConfig(host=..., port=..., user=..., password=...)`，**可自动创建数据库**。

## 2. `ModelClass` + `@table`

基类模式（`core/database/bot.py:21-23`）：

```python
class BotBaseModel(ModelClass):
    class Meta:
        database = db
```

表装饰器（`core/database/bot.py:26-33`）：

```python
@table
class Admin(BotBaseModel):
    account: Union[CharField, str] = CharField(unique=True)
    remark: Union[CharField, str] = CharField(null=True)

    @classmethod
    def is_super_admin(cls, user_id: str):
        return bool(cls.get_or_none(account=user_id))
```

`@table` 装饰器管理表结构，**启动时自动创建或更新**表结构（增删字段自动同步，**不支持更新字段类型**）。

## 3. 字段类型

| 字段类型 | 用例 |
| --- | --- |
| `CharField` | `core/database/bot.py:28` `CharField(unique=True)` |
| `IntegerField` | `core/database/bot.py:47` |
| `SmallIntegerField` | `core/database/bot.py:40` |
| `BigIntegerField` | `core/database/bot.py:249`、`core/database/group.py:24` |
| `FloatField` | `core/database/bot.py:217` |
| `BooleanField` | `core/database/bot.py:199` |
| `TextField` | `core/database/bot.py:247`、`core/database/user.py:32` |
| `ForeignKeyField` | `core/database/user.py:25` |
| `AutoField` | 本仓库未见直接使用（`@table` 自动主键） |

类型注解习惯写法 `Union[CharField, str]`（`core/database/bot.py:28`）—— 便于 IDE 把字段当 `str` 用。

常用参数：`unique=True`、`null=True`、`default=...`、`primary_key=True`（`core/database/bot.py:141`）。

`ForeignKeyField` 用法（`core/database/user.py:25`）：

```python
user_id: Union[ForeignKeyField, User, str] = ForeignKeyField(User, db_column='user_id', on_delete='CASCADE')
```

## 5. `MysqlConfig`

位置参数构造（`core/database/__init__.py:7`，本仓库实际以关键字形式传入）：

```python
MysqlConfig(**setting['config'])
```

```python
MysqlConfig(host='127.0.0.1', port=3306, user='root', password='')
```

## 7. 本项目数据库配置

`core/database/__init__.py` 提供 `config` 与 `is_mysql` 供 `bot.py:18` 使用；配置来自 `config/database.yaml`，可由环境变量覆盖（`entrypoint.py:22-36`：`ENABLE_MYSQL`、`MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`）。

> ⚠️ `entrypoint.py` 会**改写 `config/database.yaml`**。而 `entrypoint.sh:17` 所判断的 `first_run` 文件全仓无任何地方创建，因此每轮启动都会重跑 `entrypoint.py` 并覆盖配置。
