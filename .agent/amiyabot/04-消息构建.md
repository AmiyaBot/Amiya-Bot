## 1. 构造

`Chain` 第一个位置参数是触发消息，其余为关键字参数：

| 写法 | 位置 | 含义 |
| --- | --- | --- |
| `Chain(data)` | 全仓库最常见 | 回复该消息，默认 `at` |
| `Chain(data, at=False)` | `pluginsDev/src/game/wordle2/main.py:54` | 不 @ 发送者 |
| `Chain(data, at=True)` | `pluginsDev/src/talking/main.py:513` | 显式 @ |
| `Chain(data, at=False, reference=True)` | `pluginsDev/src/game/wordle2/gameStart.py:33` | 引用回复 |
| `Chain(data, chain_builder=WaitALLRequestsDone())` | 7 处 | 自定义链构建器 |
| `Chain()` | `core/__init__.py:107` | 无消息来源（主动推送） |
| `Chain(answer, at=False, reference=True)` | `pluginsDev/src/game/guess/guessStart.py:213` | 用别的 Message 作上下文 |

`is_at` 变量作参数：`pluginsDev/src/talking/main.py:513` `Chain(data, at=is_at)`。

## 3. 各方法用例

### `.text(content, auto_convert=False)`

```python
# 最简
Chain(data).text('自定义昵称已删除')                          # pluginsDev/src/user/main.py:51

# 带 [face:xx] CQ 表情码
Chain(data).text(f'博士为什么要说这种话...[face:67]（怒气值：{anger}%）')  # user/main.py:131

# auto_convert=False 关闭自动转换
reply.text(text, auto_convert=False)                          # pluginsDev/src/user/main.py:114
ask.text(story, auto_convert=False)                           # pluginsDev/src/game/guess/guessStart.py:134
```

`.text()` 返回 `Chain` 自身，支持链式串联（`pluginsDev/src/game/guess/guessStart.py:226`）：

```python
reply.text(text).text('\n图片再放大一点了哦~').image(cropper.crop(check_transparent=False))
```

发送 CQ 表情码的方式是**在 `.text()` 内嵌 `[face:67]`**（`pluginsDev/src/user/main.py:131`），而非 `.face()`。

### `.at(...)`

`pluginsDev/src/admin/main.py:88`：

```python
rep.text('\nAt用户ID：' + ' | '.join(data.at_target))
```

仓库中 `.at(` 作为**方法**仅 1 处；更常见的是用 `Chain(data, at=False)` 构造函数参数控制是否 @。

### `.image(...)`

```python
Chain(data, at=False).image(random.choice(get_face()))     # pluginsDev/src/user/main.py:94
Chain(data, at=is_at).image(reply)                          # pluginsDev/src/talking/main.py:513
chain = chain.image(content)                                # pluginsDev/src/talking/main.py:522
ask.image(cropper.crop())                                   # pluginsDev/src/game/guess/guessStart.py:65
ask.image(skill_icon)                                       # pluginsDev/src/game/guess/guessStart.py:83
```

参数接受 `str` 路径、`bytes`、PIL 图像：`cropper.crop(check_transparent=False)` 返回图像对象（`pluginsDev/src/game/guess/guessStart.py:226`）。

### `.text_image(str)`

把长文本渲染成图片：

```python
Chain().text('\n'.join(info)).text_image(traceback.format_exc())   # core/__init__.py:107
```

### `.html(file, data, width=, height=)`

`pluginsDev/src/user/mainBot.py:128`：

```python
return Chain(data).html(f'{curr_dir}/template/userInfo.html', info, width=700, height=300)
```

省略尺寸（`pluginsDev/src/game/wordle2/gameStart.py:44`）：

```python
ask = Chain(data, at=False).html(f'{curr_dir}/template/hardcode.html', process.view_data)
```

`is_template` 参数（`pluginsDev/src/talking/main.py:525`）：

```python
chain = chain.html(content, is_template=False, ...)
```

### `.markdown(str)`

`pluginsDev/src/arknights/operatorArchives/main.py:129,191`：

```python
wait = await data.wait(Chain(data).markdown(text))
```

### `.markdown_template(template_id, params)`

`pluginsDev/src/game/guess/main.py:53-58`：

```python
choice_chain = Chain(data).markdown_template(
    markdown_template_id,
    [
        {'key': 'content', 'values': [select_level]},
        ...
    ],
)
```

结构为 `(模板ID: str, [{key, values}, ...])`。

### `.voice(path)`

`pluginsDev/src/game/guess/guessStart.py:115`：

```python
ask.voice(voice_path)
```

### `.video(...)` / `.face(...)` / `.extend(...)` / `.tag(...)` / `.at_all(...)` / `.embed(...)` / `.ark(...)` / `.forward(...)`

本仓库无调用点（`.video` 仅有 COS 上传器中的 `get_video` 覆写：`core/cosChainBuilder.py:79`）。用法见上表各官方文档子页。

## 5. `InlineKeyboard`

`pluginsDev/src/game/guess/guessStart.py:162`：

```python
keyboard = InlineKeyboard(int(data.instance.appid))
```

构造参数被强转为 `int`（机器人 `appid`）。后续 `.markdown_template(...)` 与之配合用于按钮交互。
