## 4. `on_message` 参数语义

官方文档：[注册消息响应](https://www.amiyabot.com/develop/basic/messageHandler.html)

| 参数名 | 类型 | 释义 | 默认值 |
| --- | --- | --- | --- |
| `group_id` | `str` | 功能组 ID | — |
| `keywords` | — | 触发关键字，支持多种类型 | — |
| `verify` | `Callable` | 自定义校验方法，**赋值时 `keywords` 失效** | — |
| `check_prefix` | `bool` | 是否校验前缀或指定需要校验的前缀 | `True` |
| `allow_direct` | `bool` | 是否支持通过私信使用该功能 | `False` |
| `direct_only` | `bool` | 是否仅支持私信 | `False` |
| `level` | `int` | 关键字校验成功后函数的候选默认等级 | `0` |

### 4.1 `level` 是优先级

本仓库把 `level` 当作**优先级**使用，**数值越大越优先**。官方「功能优先级」节写明：*「所有函数的默认优先级都为 `1`，如果不指定优先级，分配器会按照加载的先后顺序选择」*，并允许为 `0` 或负数；而同页参数表写的默认值是 `0`。两个数值不一致，实际以 **`1`** 为准。

仓库中的实测取值：

| 值 | 位置 |
| --- | --- |
| `3` | `pluginsDev/src/arknights/calculator/main.py:34` |
| `5` | `pluginsDev/src/arknights/stage/main.py:67` |
| `10` | `pluginsDev/src/user/main.py:43` |
| `99` | `pluginsDev/src/arknights/calculator/main.py:21`（最低优先级） |
| 变量 | `pluginsDev/src/arknights/operatorArchives/main.py:20` `level=default_level` |

### 4.2 `keywords` 支持的形态

| 形态 | 位置 |
| --- | --- |
| 字符串 | `pluginsDev/src/admin/main.py:34` `keywords=['工作', '上班']` |
| 字符串列表 | `pluginsDev/src/user/main.py:43` `keywords=['昵称']` |
| `Equal(...)` | `pluginsDev/src/admin/main.py:81` `keywords=Equal('频道信息')` |
| `re.compile(...)` | `pluginsDev/src/arknights/calculator/main.py:34` `keywords=re.compile(r'多少(合成)?玉')` |

`keywords` 支持「字符串、正则、`Equal`」构成的列表；组合中包含 `Equal` 时 `Equal` 依然无视前缀检查。

### 4.3 `verify` 自定义校验

校验函数是协程，参数为 `Message`，返回「布尔值（必选）、优先级（可选）、关键值（可选）」元组：

```python
async def my_verify(data: Message):
    if 'hello' in data.text:
        return True

@bot.on_message(verify=my_verify)
async def _(data: Message):
    return Chain(data).text(f'hello, {data.nickname}')
```

结果存入 `data.verify`，含 `result` / `weight` / `keypoint` 三属性。

仓库用法：`pluginsDev/src/talking/main.py:507` `verify=check_talk, check_prefix=False, allow_direct=True`；`pluginsDev/src/arknights/recruit/main.py:316` `verify=auto_discern, check_prefix=False, allow_direct=True`；三元组用法见 `pluginsDev/src/arknights/operatorArchives/main.py:267` `verify=FuncsVerify.level_up`。

| 参数名 | 类型 | 释义 | 默认值 |
| --- | --- | --- | --- |
| `group_id` | `str` | 功能组 ID | — |
| `check_prefix` | `bool` | 是否校验前缀 | `True` |
| `allow_direct` | `bool` | 是否支持私信 | `False` |
| `direct_only` | `bool` | 是否仅私信 | `False` |

注册（`pluginsDev/src/user/mainBot.py:40`）：

```python
bot.set_group_config(GroupConfig('user', allow_direct=True))
```


**优先级规则**：仅当 `on_message` 里没有设置该参数时，功能组的参数才会对其生效；否则优先使用 `on_message` 的参数。

## 9. `timed_task`

用法：

| 用法 | 位置 |
| --- | --- |
| `each=60` | `core/__init__.py:112` |
| `each=60, run_when_added=True` | `core/__init__.py:119` |
| `each=3600, run_when_added=True` | `core/__init__.py:124` |
| `trigger='cron', hour=0` | `pluginsDev/src/weibo/main.py:555` |

回调签名统一为 `async def _(_)`（单参数）。

`run_when_added=True` 表示**注册时立即执行一次**，见 `core/__init__.py:119-121`（心跳）与 `:124-134`（清理 90 天前消息）。

cron 示例（`pluginsDev/src/weibo/main.py:555-561`）：

```python
@bot.timed_task(trigger='cron', hour=0)
async def clean_cache_task(_: BotHandlerFactory):
    setting = attridict(bot.get_config('setting'))
    retention = int(setting.get('cacheRetentionDays', 0) or 0)
    if retention <= 0:
        return
```

手动启动定时任务：`core/__init__.py:80` `bot.run_timed_tasks()`，被放入 `init_task`（`:137`）并发启动。

除 `hour` 外支持哪些 cron 字段见官方 cron 调度说明。

## 10. `event_bus`（进程内事件总线）

用法三件套：

| 操作 | 位置 |
| --- | --- |
| 订阅 | `pluginsDev/src/arknights/stage/main.py:57` `@event_bus.subscribe('gameDataInitialized')` |
| 发布 | `pluginsDev/src/arknights/arknightsGameData/builder/__init__.py:56` `event_bus.publish('gameDataInitialized')` |
| 退订 | `pluginsDev/src/arknights/stage/main.py:43` `event_bus.unsubscribe('gameDataInitialized', update)` |

事件名常量：`'gameDataInitialized'`、`'gameDataFetched'`（`pluginsDev/src/arknights/arknightsGameData/main.py:12`）。这是**插件间解耦**的推荐做法：`arknightsGameData` 插件发布，`stage`/`material`/`operatorArchives`/`recruit` 订阅。

典型模式（`pluginsDev/src/arknights/stage/main.py:37-57`）：

```python
class StagePluginInstance(AmiyaBotPluginInstance):
    def install(self):
        if self.__initialized:
            return
        self.__initialized = True

        # 资源加载完毕的回调
        event_bus.subscribe('gameDataInitialized', update)
```

> ⚠️ **`event_bus.publish` 是同步的、不重放**。订阅者若晚于发布者加载，会**永久错过**该事件。所以每个订阅者除了订阅事件，**还在自己的 `install()` 里自建索引** —— 事件的实际语义是「刷新」而非「首次初始化」。
