## 1. `http_requests`

导入（`core/__init__.py:11`）：

```python
from amiyabot.network.httpRequests import http_requests
```

GET 用法（`core/plugins/__init__.py:132-139`）：

```python
res = await http_requests.get(cos_url)
if not res:
    return req_plugins

cos_plugins = {
    item['plugin_id']: remote_config.remote.cos
    + '/plugins/official/{plugin_id}-{version}.zip'.format(**item)
    for item in json.loads(res)
}
```

`ignore_error=True` 参数（`core/__init__.py:73-76`）：

```python
await http_requests.get(
    f'{remote_config.remote.plugin}/heartbeat?appid={item.appid}',
    ignore_error=True,
)
```

官方文档：[发送 HTTP 请求](https://www.amiyabot.com/develop/tools/httpRequests.html)

- 基于 **aiohttp**，异步。
- 方法：`get`、`post`、`post_form`、`post_upload`、`request`。
- 返回值是**字符串**（失败返回空字符串），但附加属性：
  - `.json` → 尝试返回 json 化内容
  - `.response` → `aiohttp.ClientResponse` 实例（可取 `.status`）
  - `.error` → 异常实例
- `post` 默认加 `'Content-Type': 'application/json'`，请求体**仅接受字典或列表**。

参数表：

| 方法 | 参数 |
| --- | --- |
| GET | `interface: str`、`**kwargs`（aiohttp request 参数） |
| POST | `interface`、`payload: dict\|list`、`headers: dict`、`**kwargs` |
| `post_upload` | `interface`、`file: bytes`、`filename='file'`、`file_field='file'`、`payload`、`headers` |

> ⚠️ 仓库中 `http_requests` 返回字符串并用 `json.loads(res)` 解析（`core/plugins/__init__.py:139`、`pluginsDev/src/arknights/gacha/main.py:43`）。**更推荐用 `res.json`**。
>
> ⚠️ 明确**不推荐 `requests`**（同步，会阻塞事件循环）。若不可避免，用线程池转为异步，见 [处理阻塞操作](https://www.amiyabot.com/develop/advanced/blockingIO.html)。

## 2. `download_async` / `download_sync`

导入（`core/plugins/__init__.py:6`、`core/server/plugin.py:6`）：

```python
from amiyabot.network.download import download_async
```

用法（`core/server/plugin.py:148-152`）：

```python
res = await download_async(data.url)
if res:
    plugin = f'plugins/{data.packageName}'
    with open(plugin, mode='wb+') as src:
        src.write(res)
```

参数：`url: str`、`headers: dict`、`stringify: bool = False`（是否返回字符串）、`**kwargs`。默认返回 **bytes**。

`download_sync` 额外有 `progress: bool = False`（是否显示进度条）。

> ⚠️ 下载插件 zip 后**不校验哈希或签名**，只信任 HTTPS 与 COS 的完整性。

## 3. HTTP 服务器

`amiyabot.network.httpServer` 提供 `HttpServer` / `ServerConfig` / `BaseModel` 等符号，用于以 FastAPI 为底层搭建 HTTP 服务。

导入：

```python
from amiyabot.network.httpServer import HttpServer, BaseModel, ServerConfig
```

| 类型 | 用法 |
| --- | --- |
| `ServerConfig` | 服务配置：`ServerConfig(title=..., description=..., fastapi_options={...}, uvicorn_options={...})` |
| `HttpServer` | `HttpServer(host, port, config=config)` |
| `BaseModel` | 请求体模型基类 |
| `server.app` | 底层 FastAPI app，可用 `@server.app.post(...)` 直接注册路由 |
| `server.controller` / `server.route` | 控制器与路由装饰器 |
| `server.response` | 统一响应构造 |
| `server.serve()` | 启动服务 |

官方文档：[HTTP 服务器](https://www.amiyabot.com/develop/tools/httpSupport.html)

> ⚠️ **本仓库的宿主控制台服务用的是 `amiyahttp`，不是 `amiyabot.network.httpServer`**：`core/__init__.py:12-13` 为 `from amiyahttp import HttpServer, ServerConfig` 与 `from amiyahttp.auth.authKey import AuthKey`。控制台路由统一走 `@app.controller` / `@app.route`（见 [core/07-控制台API-机制与基础接口.md](../core/07-控制台API-机制与基础接口.md)），静态目录挂载见 `core/__init__.py:41` 的 `app.add_static_folder('/plugins', 'plugins')`、鉴权插件挂载见 `core/__init__.py:38` 的 `app.use_plugin(auth)`。

`amiyabot.network.httpServer` 在本仓库中的实际使用点是根目录入口脚本 `run_plugin_server.py`（`run_plugin_server.py:14` 用 `@server.server.app.get('/get_sponsors')` 注册爱发电赞助者查询接口，`:51-52` 用 `run_amiya(server.server.serve())` 启动）。该脚本启动的是一个独立的服务进程，与 `amiya.py` 共用 `core` 的模块级副作用。

```python
# run_plugin_server.py:6-7,14-15,51-52
from amiya import run_amiya
from amiyabot.util import argv

@server.server.app.get('/get_sponsors')
async def get_sponsors():
    ...

if __name__ == '__main__':
    run_amiya(server.server.serve())
```

## 4. `amiyabot.util`

| 符号 | 位置 | 用法 |
| --- | --- | --- |
| `argv` | `run_plugin_server.py:7,10-11` | `argv('afdian-token')` |
| `temp_sys_path` | `pluginsDev/buildPlugins.py:11,46-47` | 上下文管理器 |
| `extract_zip` | `pluginsDev/src/arknights/arknightsGameData/builder/__init__.py:7,74` | 解压 zip |
| `random_code` | import 1 次 | 生成随机字符串 |
| `create_dir` | `core/__init__.py:21,25` | 创建目录 |

`argv` 完整用法（`run_plugin_server.py:7-11`）：

```python
from amiyabot.util import argv

AFDIAN_USER = argv('afdian-user')
AFDIAN_TOKEN = argv('afdian-token')
```

签名：`argv(name, type=None)` —— 取命令行 `--name value`，无默认值时返回 `None`（配合 `or` 使用）；第二参数做类型转换。

> ⚠️ 参数名用**连字符**（如 `argv('afdian-token')`），不是下划线。

```python
# 带默认值与类型转换的形态（示例）
PORT = argv('port', int) or 8020
```

`random_code` 返回随机字符串。

`temp_sys_path` 用法（`buildPlugins.py:46-51`）：

```python
with temp_sys_path(parent_dir):
    with temp_sys_path(plugin):
        module = importlib.import_module(path_split[-1])
        if not hasattr(module, 'bot'):
            continue
        instance: PluginInstance = getattr(module, 'bot')
```

临时把目录加入 `sys.path`，退出时还原。这是**加载插件模块**的标准姿势。
